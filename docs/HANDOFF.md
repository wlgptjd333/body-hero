# 개발 인수인계 (v1.1.0 기준)

이 문서는 포트폴리오 정리, 배포, 기능 확장을 이어서 할 사람을 위한 개요입니다.

## 구성

| 부분 | 위치 | 설명 |
|---|---|---|
| 게임 | `project.godot`, `games/boxing/`, `scripts/` | Godot 4.6 + GDScript. 전역 상태는 `scripts/game_state.gd`와 `scripts/game_state/` 하위 모듈 |
| 인식 모듈 | `tools/udp_send_webcam_ml.py` | 웹캠 → MediaPipe Pose → 4프레임 Conv1D+GAP → 후처리 → UDP. 게임이 `scripts/game_state/webcam_bridge_internal.gd`로 실행 |
| 학습 | `tools/train_pose_classifier_seq.py`, `tools/collect_pose_data.py` | 데이터 `tools/pose_data.json`(1,105개 녹화본, 66,300프레임) |
| 실험 | `experiments/` | 졸업논문 4장 실험 스크립트와 결과 ([README](../experiments/README.md)) |
| 문서 | `docs/` | UDP 형식, GameState 규칙, UI 규칙, 설계 문서 |

## 실행 환경

- **배포판:** 릴리스 zip 안의 `tools/python_embed`. Python 3.10.11, TensorFlow 2.21(Keras 3.12), MediaPipe 1.0.1, OpenCV 4.13.
- **모델 저장 버전 주의:** Keras 3.15 이상에서 저장한 `.keras`는 embed(Keras 3.12)에서 열리지 않을 수 있습니다. 이 경우 가중치를 옮겨 embed에서 다시 저장하세요.
- **UDP 메시지 형식:** `docs/udp-protocol.md`. 게임과 인식 모듈이 함께 의존하므로 바꾸지 마세요.

## 인식 설정 (v1.1.0)

| 프로필 | 직선 펀치 확정 | 어퍼 확정 | 진입 임계값 (전체/어퍼/펀치) |
|---|---|---|---|
| precise (기본) | 3프레임 | 2프레임 | 0.95 / 0.90 / 0.88 |
| balanced | 2 | 2 | 0.93 / 0.88 / 0.85 |
| rapid | 1 | 1 | 0.85 / 0.78 / 0.72 |
| max_speed | 1 | 1 | 0.75 / 0.65 / 0.55 |

- **공통:** EMA 0.7, 해제 임계값 0.60, 쿨다운 0.12 s
- **같은 손 재무장 규칙:** 펀치 직후 같은 손 어퍼컷이 버려질 수 있습니다. v1.1에서 직선 펀치 확정을 3프레임으로 늘린 이유입니다.
- **손 대응:** 화면은 좌우 반전(cv2.flip)되어 있습니다. 사용자의 왼손 공격은 랜드마크 16, 오른손 공격은 15가 움직입니다.

## 측정값 (졸업논문 기준, 인용 가능)

- **녹화 단위 홀드아웃 20%:** 정확도 99.03%, Macro F1 99.07%
- **처음 보는 녹화 묶음(5겹 교차검증):** 87~91%
- **처리 시간:** 포즈 추정과 분류를 합쳐 프레임당 약 11 ms
- **v1.0.0 → v1.1.0 어퍼컷 정답** (실험자 1명, 게임 규칙 재생)
  - 37.3% → 91.0%
  - 설정을 정한 뒤 추가로 기록한 기록에서는 73.5% → 88.2%

## 확장 아이디어

- **게임 (중간 테스트 때 학우들이 준 피드백):**
  - 동작 속도·세기의 데미지 반영
  - 자세 안내 튜토리얼
  - 발차기 등 동작 추가
- **인식:**
  - 외부 사용자 시험 데이터
  - 사용자별 보정
  - 회전에 강한 정규화(몸통 길이, 3D 월드 좌표)
  - 오른발 앞 준비 자세 데이터
- **배포:**
  - 게임 본체는 Windows 실행 파일입니다.
  - Docker로는 학습·평가 파이프라인(`experiments/`) 재현 환경을 만드는 것이 현실적입니다.
  - 인식 모듈을 컨테이너로 돌리려면 웹캠 장치 전달(Linux)과 UDP 포트 공개가 필요합니다.
