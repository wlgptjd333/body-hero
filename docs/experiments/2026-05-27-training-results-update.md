## Recording-based Holdout 20% 결과 (2026-05-27)

**모델**: Conv1D(64, k=3) → BN → Drop(0.25) → GAP → Drop(0.3) → Dense(7)
**seq_len**: 4 (132ms context window)
**파라미터**: 19,783 (~20K)
**학습**: Adam(1e-3), EarlyStopping(patience=22), ReduceLROnPlateau(factor=0.5, patience=7)
**증강**: Gaussian noise(σ=0.03) + scale ±20% + horizontal flip + L/R swap
**분할**: 녹화 단위 holdout 20% (동일 녹화 내 시퀀스가 train/val에 섞이지 않음)

## 검증 방법론

**Recording-based holdout**:
- 동일 녹화 내 연속 프레임이 train과 val에 섞이지 않음
- 시간적 상관관계(data leakage) 제거
- 실제 게임 환경과 유사한 일반화 성능 측정

**랜덤 split(99.90%)은 비교용**:
- 논문/다른 연구와의 직접 비교를 위한 참고치
- 실제 일반화 성능은 recording-based holdout(99.22%)이 더 정확함
