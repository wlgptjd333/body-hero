# 졸업논문 4장 실험 자료

졸업논문 「단일 웹캠 기반 경량 1D-CNN 동작 인식을 활용한 실시간 2D 복싱 체감형 게임의 설계 및 구현」 제4장의 실험 스크립트와 결과를 모아 둔 폴더입니다. 학습 데이터는 저장소의 `tools/pose_data.json`, `tools/pose_recordings_meta.json`입니다.

| 폴더 | 논문 절 | 내용 |
|---|---|---|
| `fixed_split/` | 4.5~4.11 | 녹화 단위 고정 분할 반복 비교 실험(5개 시드): 학습·평가 스크립트, 결과 JSON·CSV, 학습된 모델 |
| `extra_v15/` | 4.11~4.14 | 입력 길이 추가 비교, 녹화 묶음 단위 5겹 교차검증, 임계값 비교, 합성 변형 시험, 지연 측정 |
| `realplay/` | 4.15 | 1인 실제 플레이 기록 도구(`play_lab.py` 등)와 회차별 기록·분석, v1.1 모델 비교 보고서 |

## 참고

- `realplay/results/*/frames.jsonl.gz`는 회차별 관절 좌표와 실제 입력 기록입니다. 영상은 저장하지 않았습니다. 참가자는 "P1(참가자 1, 학습 데이터 녹화자)"로 익명화했습니다.
- 예측 확률 파일(`.npy`)과 큰 학습 로그는 용량 때문에 뺐습니다. 저장된 모델과 스크립트로 다시 만들 수 있습니다.
- 스크립트 안의 `C:\Users\...` 경로는 실험 당시 PC의 경로입니다. 다시 실행할 때는 데이터와 모델 경로를 자기 환경에 맞게 바꿔 주세요.
- 실험 환경: Python 3.10 계열, TensorFlow/Keras 3, MediaPipe Pose. 자세한 PC 사양과 버전은 논문 표 5.에 있습니다.
