# 실플레이 실험 계획 토론과 1시간 안

## 1. 토론: 논문의 어떤 주장에 실플레이 근거가 필요한가

v26 원고 가운데 실데이터 없이 합성 데이터나 녹화본으로만 뒷받침한 주장을 골랐습니다. 이를 시스템, 비전, ML 방법론, HCI 심사위원 관점에서 따져 봤습니다.

| 논문의 주장 | 심사에서 나올 말 | 필요한 실플레이 |
|---|---|---|
| GAP 4프레임은 중간 자세·순간 동작에서 의도하지 않은 공격과 다른 공격이 적다(4.13, 4.14) | "합성 보간이지 실제 동작이 아니잖아" | 실제 지시 동작(특히 어퍼컷), 준비 자세 대기 |
| LSTM 3프레임은 약 1프레임 빠르다 | "실제 반응도 그런가" | 같은 지시 동작 데이터로 계산 가능 |
| GAP 4프레임은 짧은 공격을 놓칠 수 있다(반대 근거) | "불리한 쪽도 확인했나" | 빠른 잽 |
| 처음 보는 조건에서는 성능이 떨어진다(4.12) | "실제 환경이 바뀌면?" | 조명 끔, 발이 잘리는 좁은 공간 |
| 새 사용자 성능은 검증하지 않았다(한계) | "사람이 바뀌면?" | 학습 데이터 녹화에 참여하지 않은 사람 |
| 몸을 돌리면 정규화가 약해진다(3.4 한계) | "얼마나 약해지나" | 비스듬히 서기 |

**패널 결론.** 모델 비교는 같은 프레임을 모든 모델에 넣는 **짝지은 비교**입니다. 사람, 회차, 컨디션의 차이가 모델 사이에서는 상쇄되므로, 큰 차이(예: 어퍼컷 때 펀치 먼저 10% 대 62%)는 수십 회로도 충분히 드러납니다. 반복을 늘리기보다 **서로 다른 조건을 하나씩** 넣는 쪽이 논문에 더 도움이 됩니다.

## 2. 분류

### 꼭 필요한 실험 → ① 본 실험

| 블록 | 이유 |
|---|---|
| 지시 동작 ×2 (128회, 어퍼컷 48회) | 4.13·4.14의 핵심 주장을 실데이터로 확인합니다(다른 공격 먼저, 정답 발동, 지연). |
| 준비 자세 대기 (왼발·오른발 앞) | 1회차에서 오발동이 실제로 난 자세입니다. 오른발 앞 치우침도 확인합니다. |
| 빠른 잽 ×1 (24회) | GAP 4프레임에 불리한 쪽의 근거입니다. 이게 빠지면 "유리한 실험만 했다"는 비판을 받습니다. |
| 비스듬히 서기 ×1 (20회) | 3.4절의 한계를 수치로 보여 줍니다. 1회차에서 차이가 컸습니다(8% 대 40%). |
| 정자세·움직이며 대기 | 기준값 역할입니다. 각 45초로 짧습니다. |

### 있으면 좋은 실험 (각 6~8분)

| 회차 | 이유 |
|---|---|
| ② 조명 끔 | 바꾸기 쉬운 환경 조건입니다. "처음 보는 조건"(4.12)의 실제 예가 됩니다. |
| ③ 좁은 공간(발 잘림) | 1회차의 오른손 오발동이 공간 탓인지 가릴 수 있습니다. 실제 집 플레이 환경이기도 합니다. |
| ④ 다른 사람 1명 | 새 사용자에 대한 **유일한 근거**입니다. 구할 수 있으면 가장 가치가 큽니다. |

### 빼도 되는 실험

| 실험 | 빼는 이유 |
|---|---|
| 기본 조건 3회 반복 | 짝지은 비교라 1회 ×2배로 충분합니다. 같은 사람을 반복해도 일반화 근거는 늘지 않습니다. |
| 좌우 연타 | 1회차에서 모든 모델이 98~100%라 구분력이 없습니다. |
| 역광, 멀리 | 만들기 어렵고, 논문에 이와 관련된 주장이 없습니다. |
| 화면 반응 지연(휴대폰) | 논문은 "끝단 지연 미측정"을 한계로 둡니다. 실제 게임과 시뮬레이션의 차이(150 ms)는 이미 이 도구로 잽니다. |

## 3. 1시간 안

| 순서 | 회차 설정(시작 화면 버튼) | 실험 시간 | 준비·쉬기 포함 |
|---|---|---|---|
| 1 | **① 본 실험** (발까지 보임, 조명 켬) | 약 17분 | 약 22분 |
| 2 | **② 조명 끔** | 약 7분 | 약 10분 |
| 3 | **③ 좁은 공간** (발이 잘리게 약 1 m 다가가기) | 약 6분 | 약 8분 |
| 4 | (선택) **④ 다른 사람** | 약 8분 | 약 10분 |
| | **합계** | 30~38분 | **40~50분** |

시작 화면 위쪽의 회차 버튼을 누르면 블록, 반복, 촬영 조건이 자동으로 맞춰집니다. 이름, 메모, 학습 데이터 참여 여부만 바꾸면 됩니다.

## 4. 이 정도면 논문에 쓸 만한가 (정밀도 점검)

| 지표 | ① 본 실험의 시행 수 | 판단 |
|---|---|---|
| 어퍼컷 때 펀치 먼저 | 어퍼컷 58회(지시 48 + 비스듬히 10) | 10% 대 60% 수준의 차이라면 95% 구간(약 ±8%p, ±13%p)이 겹치지 않습니다. **충분** |
| 다른 공격 먼저(전체) | 148회 | 충분 |
| 반응 지연 차이(약 40 ms) | 짝지은 시행 100회 이상 | 중앙값 비교에 충분 |
| 빠른 잽 놓침 | 24회 | 85% 아래로 떨어지는 큰 차이만 잡습니다. 1회차처럼 둘 다 99~100%면 "차이 없음"까지만 말할 수 있습니다 |
| 오발동(1분당) | 쉬는 구간 약 5.5분 + 준비 자세 대기 1.5분 | 1분당 2건 수준이면 약 14건이라 경향만 말할 수 있습니다. **"참고 수치"로 씁니다** |

- 모든 결과는 1명(②·③은 같은 사람)의 실험입니다. ④가 없으면 새 사용자 성능은 계속 한계로 남습니다.
- 논문에는 "1인 예비 실사용 확인"으로 짧게 넣는 것을 권합니다. 짝지은 비교라 모델 간 차이는 주장할 수 있고, 절대 수치는 참고값으로 씁니다.
