# Body Hero v1.1.0 인식 변경 사항

## 바뀐 것

| 항목 | v1.0.0 | v1.1.0 |
|---|---|---|
| 분류 모델 `pose_classifier_seq_len4.keras` | 5/27 학습 모델 | 같은 구조(4프레임 Conv1D+GAP, 19,783 파라미터)를 논문 반복 비교 실험과 같은 설정으로 학습한 모델(녹화 단위 고정 분할, 시드 44, 실제 거울상 좌우 반전 증강) |
| Precise 프로필의 직선 펀치 확정 프레임 | 2 | **3** (어퍼컷 2, 스쿼트 3은 그대로. Balanced는 2, Rapid·Max Speed는 1 그대로) |
| `--upper-windup-punch-suppress` 손목·어깨 판정 | 좌우 손목이 뒤바뀜 | 좌우 수정 (옵션은 여전히 기본 꺼짐) |

- 모델은 게임의 python_embed(Keras 3.12.4)에서 다시 저장했습니다. 실험 환경(Keras 3.15.1)에서 학습한 모델과 출력이 같습니다.
- v1.0.0 게임과 모델은 태그 `v1.0.0`에 그대로 있습니다.

## 바꾼 이유 (실플레이 기록, 2026-10-17·18, 실험자 1명)

- **v1.0.0의 어퍼컷 문제.** 어퍼컷을 올리는 도중 직선 펀치가 먼저 확정되면, 같은 손 재무장 규칙 때문에 뒤따르는 어퍼컷이 버려졌습니다.
- **v1.0.0의 오른발 앞 오발동.** 오른발을 앞에 둔 준비 자세에서 오른손 펀치 오발동이 났습니다. 학습 데이터의 "대기"에서 오른발 앞 자세는 9%뿐이었고, "오른손 펀치"에서는 32%였습니다.
- **같은 기록을 게임 규칙으로 재생한 비교(기본 조건, 10/17).**

| 지표 | v1.0 | v1.1 |
|---|---|---|
| 지시 동작 정답 | 78% | 97% |
| 어퍼컷 정답 | 37% | 91% |
| 다른 공격 먼저 | 25% | 4% |
| 빠른 잽 | 100% | 100% |

- **v1.1 실시간 확인(10/18, 좁은 공간).**
  - 지시 동작 정답 98.4%, 다른 공격 먼저 1.6%, 빠른 잽 100%
  - 오른발 앞 준비 자세 오발동: 0회(같은 기록을 v1.0 모델로 재생하면 분당 15.3회)
- **확정 프레임을 3으로 둔 이유.** 10/17 기록은 어퍼컷을 팔꿈치를 펴며 올린 시행이 많았습니다. 이 기록에서 1·2·3프레임의 어퍼컷 정답은 69·73·91%였습니다. 10/18 기록은 팔꿈치를 직각에 가깝게 유지했고, 1·2·3프레임 모두 88%로 같았습니다. 그 대신 공격 발동이 1프레임 대비 약 30 ms 늦습니다.
  - 동작을 정확히 하면 2프레임으로도 충분합니다. 하지만 기본값은 동작이 서툰 경우에도 오류가 적은 3프레임으로 둡니다.
  - 더 빠른 반응을 원하면 설정에서 Balanced(2프레임)를 고르세요.
- **플레이 요령.** 어퍼컷은 팔꿈치를 직각에 가깝게 유지한 채 아래에서 위로 올리면 펀치로 잘못 인식되는 경우가 줄어듭니다.
- 위 수치는 같은 사람(학습 데이터 녹화자)의 기록입니다.
