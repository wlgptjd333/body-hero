# Body Hero v1.1 인식 변경 사항

## 바뀐 것

| 항목 | v1.0.0 | v1.1 |
|---|---|---|
| 분류 모델 `pose_classifier_seq_len4.keras` | 5/27 학습 모델 | 같은 구조(4프레임 Conv1D+GAP, 19,783 파라미터)를 논문 반복 비교 실험과 같은 설정으로 학습한 모델(고정 분할, 시드 44, 실제 거울상 좌우 반전 증강) |
| Precise 프로필의 직선 펀치 확정 프레임 | 2 | **3** (어퍼컷 확정 2, 스쿼트 3은 그대로) |
| `--upper-windup-punch-suppress` 손목·어깨 판정 | 좌우 손목이 뒤바뀜 | 좌우 수정 (옵션은 여전히 기본 꺼짐) |

- 모델은 게임의 python_embed(Keras 3.12.4)에서 다시 저장해 그대로 읽힙니다. 실험 환경(Keras 3.15.1)에서 학습한 모델과 출력이 같습니다(최대 차이 0).
- v1.0.0 게임과 모델은 태그 `v1.0.0`에 그대로 있습니다.

## 바꾼 이유 (실플레이 기록 재생, 2026-10-17)

- **v1.0.0의 문제.** 어퍼컷을 올리는 도중 펀치가 먼저 확정되었고, 그 뒤 같은 손 재무장 규칙이 어퍼컷을 버렸습니다. 기본 조건 재생에서 어퍼컷 정답은 37%였습니다.
- **v1.0.0의 다른 문제.** 오른발 앞 준비 자세에서 오른손 펀치 오발동이 났습니다. 학습 데이터의 "대기" 가운데 오른발 앞 자세는 9%뿐이었습니다.
- **v1.1 재생 결과(기본 조건).**
  - 지시 동작 정답 97%(v1.0 78%)
  - 어퍼컷 91%(37%)
  - 다른 공격 먼저 4%(25%)
  - 빠른 잽 100%(100%)
  - 조명 끔 회차의 준비 자세 오발동 분당 2.0회(v1.0 14.6회)
  - 공격 발동 지연은 약 20 ms 늘었습니다.
- 위 수치는 같은 사람(학습 데이터 녹화자)의 기록을 재생한 값이라, 새 기록으로 다시 확인해야 합니다.
